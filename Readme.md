
# Job Market

Job Market is a web-based job search application built using HTML, CSS, and JavaScript. It allows users to explore job opportunities, filter jobs based on their preferences, and apply for suitable positions through the application.

## Features

- Search jobs by role or job title.
- Filter jobs by office city.
- Filter jobs based on minimum salary.
- Filter jobs by experience level.
- Filter jobs based on remote work options.
- Display job details dynamically.
- Apply for jobs through the application.
- Fetch job listings from a public REST API.
- Responsive user interface for different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- REST API
- JSON

## Job Search Filters

| Filter | Description |
|---|---|
| Role | Search jobs by job title or role |
| Office City | Filter jobs by location |
| Minimum Salary | Find jobs matching the minimum salary requirement |
| Level | Filter jobs by experience level |
| Remote Option | Find remote job opportunities |

## API Integration

This application uses the Artificial Intelligence Jobs API to retrieve job listings.

**API Endpoint:**

https://artificialintelligencejobs.co/api/jobs
